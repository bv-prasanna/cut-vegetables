# Screenshot-based UI implementation

The public FreshPrep home page follows the approved reference composition: leaf wordmark, horizontal navigation, kitchen-ready hero, visual preparation catalogue, weekday recurrence panel, delivery cut-off cards, offers/rewards preview, trust highlights and footer.

Navigation preserves existing local demo catalogue, standing orders, order list and operations configuration. Product prices in placeholder cards are explicitly not invented; banners and rewards are labelled previews rather than active campaigns. External stock images are temporary and must be replaced with actual cut-size photos and owned campaign assets before launch.

**Not completed:** production login, customer account management, real offers/loyalty, CMS-backed sliders, production/packing/QC/driver screens, PostgreSQL integration with the web UI, verified automated builds and UAT. The local demo is not safe for public deployment.

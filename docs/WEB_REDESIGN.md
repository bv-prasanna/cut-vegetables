# Professional B2B workspace UI pass

This commit replaces the cartoon-style initial page with a polished, responsive workspace shell. Implemented UI paths: dashboard, filtered visual catalogue, basket/one-off demo order, standing-order demo creation, local order listing, and admin vegetable + delivery slot configuration.

## Quality caveat
This is a **frontend design/interaction improvement**, not a claim of complete business implementation. The /api proxy still points to the in-memory development API. No production RBAC, customer profile, persistent backend integration, true hero CMS, loyalty rules, payment, procurement, QC or delivery screens are connected. No build or screenshot verification has been completed for this commit. Keep developer endpoints offline only.

## Design direction
Desktop side navigation, restrained forest-green palette, typography hierarchy, responsive product cards, precise size labels, customer cart summary, slot cutoff visibility, clear empty states, and distinct operations setup. Replace placeholder photos with representative images of actual vegetable cuts before launch.
